### 文件结构

```
public/data/chapter1/
├── manifest.json          # 场景清单
├── scene_001.json         # 场景1：深夜的试探

```

#### 1. `manifest.json`（场景清单）

json复制

```json
{
  "chapter": 1,
  "scenes": [
    {
      "id": "scene_001",
      "file": "scene_001.json",
      "title": "深夜的试探",
      "nextScene": "scene_002"
    },
    {
      "id": "scene_002",
      "file": "scene_002.json",
      "title": "妻子的电话",
      "nextScene": "scene_003"
    }
  ]
}
```

#### 2. `scene_001.json`（单个场景）

json复制

```json
{
  "sceneId": "scene_001",
  "nodes": [
    {
      "id": "msg_001",
      "type": 1,
      "content": "你还醒着吗？",
      "delay": 1000,
      "next": "msg_002"
    },
    {
      "id": "msg_002",
      "type": 2,
      "choices": [
        {
          "text": "还没睡",
          "next": "msg_003",
          "nextScene": "scene_001",
          "effects": { "trust": 5 }
        },
        {
          "text": "已经睡了",
          "next": "msg_004",
          "nextScene": "scene_001",
          "effects": { "trust": -2 }
        }
      ]
    }
  ]
}
```

**关键字段**：

- `next`：同场景内跳转（节点 ID）
- `nextScene`：跨场景跳转（场景 ID）

### 引擎加载逻辑

#### 初始化

```javascript
// 1. 只加载 manifest.json（很小，~5KB）
const manifest = await fetch('/data/chapter1/manifest.json').then(r => r.json());

// 2. 加载第一个场景
let currentScene = await loadScene(manifest.scenes[0].file);
```

#### 场景切换

```javascript
async function handleNext(node) {
  if (node.nextScene) {
    // 跨场景跳转 → 加载新场景
    currentScene = await loadScene(getSceneFile(node.nextScene));
  }
  
  // 找到下一个节点
  const nextNode = currentScene.nodes.find(n => n.id === node.next);
  displayNode(nextNode);
}

async function loadScene(sceneFile) {
  // 缓存已加载的场景
  if (sceneCache[sceneFile]) {
    return sceneCache[sceneFile];
  }
  
  const scene = await fetch(`/data/chapter1/${sceneFile}`).then(r => r.json());
  sceneCache[sceneFile] = scene;
  return scene;
}
```

### **消息类型定义（type字段）**

| type | 说明                  | 必填字段                       |
| :--- | :-------------------- | :----------------------------- |
| 1    | 对方发言（叶晓阳）    | id, type, content, delay, next |
| 2    | 我方发言（选项）      | id, type, choices[]            |
| 3    | 对方发图片            | id, type, imageUrl, next       |
| 4    | 自己发图片            | id, type, imageUrl, next       |
| 5    | 动态                  | id, type, content, next        |
| 6    | 系统消息（离线/上线） | id, type, content, wait, next  |
| 7    | 结局                  | id, type, endingId             |

------

### **字段说明**

| 字段        | 类型   | 说明                            |
| :---------- | :----- | :------------------------------ |
| `id`        | string | 唯一消息ID（用于跳转和存档）    |
| `type`      | number | 消息类型（1-7）                 |
| `content`   | string | 文本内容（type:1/2/5/6必填）    |
| `imageUrl`  | string | 图片路径（type:3/4必填）        |
| `delay`     | number | 显示延迟（毫秒），默认0         |
| `wait`      | number | 等待时间（毫秒），模拟思考/离线 |
| `next`      | string | 下一条消息ID（同场景内跳转）    |
| `nextScene` | string | 下一场ID（跨场景跳转）          |
| `choices`   | array  | 选项列表（type:2必填）          |
| `effects`   | object | 数值影响（如 `{"trust": 5}`）   |
